# Program Rekap dan Analisis Nilai Matematika Kelas

## Deskripsi
Program konsol berbasis Python untuk membantu guru matematika membaca data nilai, memvalidasi data, menghitung statistik kelas, dan menentukan status ketuntasan siswa secara otomatis.

## Fitur
- Membaca data nilai otomatis dari file teks.
- Validasi nilai pada rentang 0 hingga 100.
- Perhitungan statistik otomatis (rata-rata, nilai minimum, nilai maksimum).
- Rekapitulasi jumlah siswa tuntas berdasarkan KKM.

## Persyaratan
- Python 3.x

## Cara Menjalankan
1. Clone repositori ini atau buka folder proyek di VS Code.
2. Jalankan file utama melalui terminal terintegrasi:
   ```bash
   python main.py
